Objetivo:

Alinear las rutas físicas utilizadas por PublishIndexStore con las utilizadas actualmente por el consumidor principal.

Contexto:

Actualmente PublishIndexStore guarda:

publish-index/<phase>.json

y los ZIP en:

<phase>/<filename>

Queremos utilizar exactamente estas rutas:

Índice:

<phaseFolder(phase)>/publish-index.json

ZIP:

<phaseFolder(phase)>/<filename>

Mapa de phaseFolder:

PRIMES -> primes
PRODUCTS -> products
ANCHORS -> anchors
ANCHOR_SIEVE -> sieves/anchor-sieve
FACTORS -> factors
SMALL_CERTIFICATES -> certificates/small
SUCCESSIVE_SIEVES -> sieves/successive
FINAL_CERTIFICATION -> certificates/final

Tareas:

1. Añadir una función interna phaseFolder().
2. Utilizarla para índices.
3. Utilizarla para ZIPs.
4. Mantener APIs públicas sin cambios.
5. Actualizar tests.
6. Build y tests verdes.

Importante:

No modificar contratos públicos.
No cambiar funcionalidades.
No tocar checkpoints.
Solo cambiar la ubicación física utilizada internamente.
