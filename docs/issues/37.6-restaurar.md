Objetivo:

Restaurar la compatibilidad total de ProjectStateStore con el formato histórico utilizado por el sistema.

Problema:

Actualmente ProjectStateStore utiliza:

project-state/project-phases.json

Pero el sistema histórico utiliza:

project-phases.json

en la raíz del repositorio.

Esto impide:

- leer estados históricos existentes
- mantener compatibilidad de escritura
- reutilizar los datos ya publicados

Tareas:

1. Localizar la referencia fija utilizada por ProjectStateStore.

2. Sustituir:

project-state/project-phases.json

por:

project-phases.json

3. Mantener exactamente:

- formato
- validaciones
- API pública
- errores

4. Actualizar los tests que dependan de la ruta antigua.

5. Verificar:

- lectura de estados existentes
- persistencia
- sobrescritura de estado

6. No modificar:

- PublishIndexStore
- Checkpoints
- ArtifactStorage
- GithubArtifactStorage

7. Entregar:

- diff resumido
- líneas modificadas
- resultado de tests

8. Build y tests verdes.

Importante:

No crear migraciones.

No mantener doble escritura.

No introducir compatibilidad temporal.

La nueva referencia debe coincidir exactamente con la utilizada históricamente por el sistema:
project-phases.json
